fix: loading banner, speed/upload counting, add pause/resume (v1.12.3)

Critical fixes:
- Loading banner never disappears: race condition where backend sent
  'ready' before WebSocket connected. Frontend now clears banner on
  WS connect by fetching current state.
- Uploaded/ratio/duration not counting: display path (every 3s) did
  not accumulate uploaded bytes, only stealth path (every ~30min) did.
  Moved byte accumulation to display path for continuous updates.
- Ultra-low speed (5% of min): leechers==0 triggered background speed
  even when seeders > 0. Fixed: background speed only when swarm is
  truly dead (both seeders=0 AND leechers=0).

New feature:
- Per-torrent pause/resume: pause button per row in dashboard.
  Paused torrents stop announcing without archiving and are excluded
  from auto-resume. Column renamed Del -> Actions.
  Backend: POST /api/torrents/{hash}/pause and /resume endpoints.
